## 阶段 1：检索质量（1—2 周）

- [ ] 业务同义词词典：开票/发票、师傅/工程师、被偷/丢失、晚还/逾期
- [ ] Query expansion：基于同义词和用户日志扩展查询
- [ ] 混合检索：BM25 + 轻量 embedding（可选 sentence-transformers）
- [ ] Rerank：Top10 → cross-encoder 或 LLM rerank
- [ ] 困难子集 Hit@3 从 60% 提升到 85%+
- [ ] 新增 50 条真实风格问法，避免评测集过拟合

**验收**：困难子集 Hit@3 ≥ 85%，简单子集不下降；新增失败案例进入报告。

## 阶段 2：对话与工具（2—3 周）

- [ ] 多轮槽位填充：设备、数量、天数、距离、订单号
- [ ] 指代消解：“这个设备”“上回那个订单”
- [ ] 工具错误码标准化：参数缺失、未找到、权限不足、超时
- [ ] 报价审批流：折扣/特殊条款触发人工
- [ ] 订单查询权限：手机号后四位/验证码
- [ ] 工单系统对接：飞书/企微/CRM

**验收**：多轮任务完成率 ≥ 80%；工具错误可解释；高风险操作 100% 人工确认。

## 阶段 3：内容与增长（2 周）

- [ ] 接入 LLM Writer，支持品牌语气 few-shot
- [ ] 10 个内容模板：清单、案例、对比、避坑、政策解读
- [ ] 素材库：设备图、现场图、资质图
- [ ] UTM/CTA 规范，打通内容—线索
- [ ] A/B 标题测试
- [ ] 自动周报：渠道、选题、CPL、线索

**验收**：单篇初稿时间下降 50%；合规高风险拦截率 100%；周报自动生成。

## 阶段 4：投标与流程（2—3 周）

- [ ] PDF 解析 + OCR（扫描件）
- [ ] 表格解析：设备清单、评分表、报价表
- [ ] 评分办法结构化：技术/商务/价格权重
- [ ] 投标检查清单导出 Excel
- [ ] 流程工时日志，替代纯访谈估算
- [ ] ROI 模型：人力成本、错误成本、实施成本

**验收**：10 份历史招标文件字段抽取准确率 ≥ 90%；关键日期/预算 100% 人工复核。

## 阶段 5：生产化（长期）

- [ ] 用户/权限/租户
- [ ] 知识库版本、审核、过期提醒
- [ ] 审计日志、数据脱敏、保留期限
- [ ] 监控：转人工率、一次解决率、P95 延迟、成本
- [ ] A/B 实验与灰度发布
- [ ] 模型路由：不同任务用不同模型，控制成本
- [ ] 安全：Prompt 注入、越权、敏感信息

## 优先级原则

1. **先做能测量的**：没有基线和验收标准的场景，不立项。
2. **先做低风险的**：高风险场景先辅助，不自动执行。
3. **先做数据就绪的**：数据都没有，先补数据，不要先接模型。
4. **先做可复用的**：知识库、评测、工具 schema、指标字典是基础设施。
5. **不要为了 AI 而 AI**：确定性规则能解决的，不要用模型。

## 如果只有 6 个月实习，怎么排

| 月份 | 目标 |
| --- | --- |
| M1 | 业务调研、流程梳理、数据审计、评测集 |
| M2 | 客服 FAQ RAG + 转人工，灰度 |
| M3 | 报价/订单工具，人工确认 |
| M4 | 内容 Workflow + 合规检查 |
| M5 | 投标摘要 / 流程机会矩阵，选一个落地 |
| M6 | 复盘、指标、知识库运营机制、交接文档 |

这个排期不是承诺，而是说明“先做低风险、可测量、可复用的东西”。
